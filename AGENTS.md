# One-Day Todo App

Deliver a small, complete todo product. Preserve the two test seams: Flask HTTP behavior and the rendered React user interface. Keep persistence inside the backend modules and HTTP details inside the frontend client.

Run `make check` before declaring a change complete. A change is complete when its behavior is covered at the relevant seam and every check passes.

## Context pointers

- Architecture: read `.agents/skills/codebase-design/SKILL.md` when adding a module, interface, seam, or adapter.
- Tests: read `.agents/skills/tdd/SKILL.md` when changing behavior or fixing a defect.
- Agent guidance: read `.agents/skills/writing-for-agents/SKILL.md` when editing an `AGENTS.md` file.
- Review: read `.agents/skills/code-review/SKILL.md` before reviewing a branch or worktree.

`skills-lock.json` is the source of truth for installed project skills.
